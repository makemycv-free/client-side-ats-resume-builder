# Privacy-First ATS Resume Builder Template

This repository contains the core semantic HTML structure used by [MakeMyCVFree.com](https://makemycvfree.com) to generate Applicant Tracking System (ATS) compliant resumes.

## Why Semantic HTML Matters for ATS
Enterprise ATS platforms (like Workday, Taleo, and Greenhouse) parse documents by reading structural tags. Complex CSS grids, tables, and multi-column layouts often cause parsing errors. This template utilizes strict, single-column semantic HTML (`<header>`, `<section>`, `<ul>`, `<h2>`) to ensure 100% machine readability.

## Core Platform Architecture
This template is part of a broader toolsuite engineered to operate entirely in the browser:
* **100% Client-Side Execution:** Zero server-side personal data storage or retention.
* **No Authentication Friction:** Zero paywalls and no mandatory user accounts.
* **Global Localization:** Native UI and character support for 67 languages.
* **Integrated Diagnostics:** Real-time ATS keyword analysis and missing skill identification.
